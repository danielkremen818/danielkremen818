## 🚀 Featured project

### [ultracost](https://github.com/danielkremen818/ultracost) — per-stage model routing for Claude Code

Keeps a single `ultracode` dynamic workflow from silently running every subagent on Opus. Injects a quality-first routing policy each session, statically guards `agent()` stages that would inherit the session model, and gates every launch with a cost estimate. Zero dependencies · no telemetry · MIT.
